These rules define how internet addresses are written and formatted in Helsana correspondence. The rules define formatting only. They must not be used to infer, construct, translate or change the factual internet address. Preserve the internet address from the source content and apply only the formatting rules corresponding to the requested output language.

### ruleID: `cpm-kbs-internet-address-001`

**Instruction:** Write internet addresses without the protocol prefix (https:// or http://) and without www.. Display only the domain and, where applicable, the path. If an internet address appears at the end of a sentence, add the sentence-ending full stop after the internet address. These formatting rules apply only to the displayed text and must not modify the underlying hyperlink target.

**Correct:**
- `helsana.ch`
- `helsana.ch/myhelsana`
- `helsana.ch/versicherungen`
- `Weitere Informationen finden Sie auf helsana.ch.`

**Incorrect:**
- `www.helsana.ch`
- `https://helsana.ch`
- `https://www.helsana.ch`
- `http://helsana.ch`
