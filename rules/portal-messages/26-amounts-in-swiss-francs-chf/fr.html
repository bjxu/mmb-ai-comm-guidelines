Montants en francs/CHF/Devises

L’abréviation courante est CHF : elle correspond au code international pour les francs suisses (ISO-4217).

Nous écrivons les montants de la manière suivante :

  • avec des centimes : CHF 2.50
  • sans centimes CHF 200.– (avec tiret long*) Exemple : CHF 200.– sont à gagner.
  • dans les tableaux : CHF 6.00 (toujours avec 00)

* Pour faire un tiret long dans Word : appuie sur la touche Ctrl et le moins sur le pavé numérique (-).

Dans tous les autres programmes, Alt et 0150.

Exception dans le Marketing : écriture des montants en francs dans les textes éditoriaux

Devises

Montants dans le texte :

  • EUR avec centimes : EUR 2.50
  • EUR sans centimes : EUR 200.–
  • USD avec centimes : USD 2.50
  • USD sans centimes : USD 200.–

Montants dans les tableaux :

  • EUR avec centimes : EUR 6.50
  • EUR sans centimes : EUR 6.00 (toujours avec deux zéros)
  • USD avec centimes : USD 6.50
  • USD sans centimes : USD 6.00 (toujours avec deux zéros)
